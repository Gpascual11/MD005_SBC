# MD005 – Sistemes Basats en el Coneixement

Knowledge-Based Systems coursework developed during the **La Salle Barcelona – Data Science Master**.

This repository contains practical implementations of Machine Learning, Deep Learning, and Knowledge-Based System techniques, covering both theoretical concepts and applied experimentation using Jupyter notebooks.

---

## Objectives

The goal of this repository is to:

* Explore core algorithms used in Knowledge-Based Systems
* Implement and analyze supervised and unsupervised learning models
* Understand parameter optimization and model evaluation
* Apply Deep Learning techniques to real-world datasets
* Develop practical problem-solving skills through experimentation

---

## Repository Structure

### 1. Clustering

Unsupervised learning techniques for pattern discovery and segmentation.

Topics covered:

* K-Means
* Hierarchical clustering
* Cluster validation techniques
* Feature preprocessing for clustering tasks

---

### 2. Classification

Supervised learning algorithms for categorical prediction problems.

Implemented models:

* Decision Trees
* k-Nearest Neighbors (kNN)
* Logistic Regression
* Performance evaluation metrics

---

### 3. Regression

Predictive modeling for continuous target variables.

Includes:

* Linear Regression
* Model evaluation metrics
* Bias-variance analysis
* Feature engineering strategies

---

### 4. Parameterization and Supervised Learning

Advanced tuning and training techniques.

Topics include:

* Hyperparameter optimization
* Cross-validation strategies
* Model generalization techniques
* Training pipeline improvements

---

### 5. Deep Learning

Introduction to neural networks and deep architectures.

Covered concepts:

* Neural network fundamentals
* Training strategies
* Model evaluation
* Practical Deep Learning experiments

---

### 6. Final Project

Project of Gaussian Mixture Model (GMM)
